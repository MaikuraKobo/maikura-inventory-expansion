# Maikura Inventory Expansion

Adds configurable extra inventory space from 9 to 54 slots for Minecraft Fabric.

## Features

- Adds extra inventory slots to the player inventory
- Configurable from 9 to 54 slots
- Integrated directly into the vanilla inventory screen
- Per-player inventory storage
- Death-safe storage
- Mod Menu configuration support

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Fabric API
- Mod Menu (optional)

## Configuration

Available sizes:

- 9 slots
- 18 slots
- 27 slots
- 36 slots
- 45 slots
- 54 slots
